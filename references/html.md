# HTML 交付规格

HTML 分支读这一份。中英文用户共用。正文的写作要求一条不减，这里只管页面、图、交互和标注层。

## 1. 页面骨架：照抄 reader-kit

页面从 `references/reader-kit.html` 起步，不自己设计骨架。文件里有六段带 START / END 注释的块，**整段复制，一个字不改**：

| 块 | 放在哪 | 管什么 |
|---|---|---|
| `XRAY HEAD` | `<head>` | 首屏定主题（不闪白）、KaTeX |
| `XRAY PAGE CSS` | `<style>` 开头 | 版式、配色变量、笔记本块、标注层样式 |
| `FIGKIT TOKENS` | 紧跟在上一块后面 | 角色色和图的样式，来自 `references/figure-kit.html` |
| `XRAY BODY TOP` | `<body>` 开头 | 顶栏四个键、目录栏、`<main>` 开头 |
| `XRAY BODY BOTTOM` | 正文之后 | `</main>`、标注数据块 `xray-notes`、`XRAY JS` |
| `FIGKIT JS` | 紧跟在上一块后面 | 画图 API，来自 `references/figure-kit.html` |

最后一个 `<script>` 里写这篇文档自己的图，全部包在 `XRAY.ready(function () { ... })` 里。

正文写在 `<main>` 里，h2、h3 必须是 `<main>` 的直接子元素，目录、折叠、标注都靠这一点找到章节。`<html lang>` 写 `zh-CN` 或 `en`，标注层的按钮文字跟着它切换。

`xray-notes` 块里的 `doc` 在生成时填好：`{"title":"文档标题","source":"论文名或主题","made":"YYYY-MM-DD","lang":"zh","file":"文件绝对路径"}`。`marks`、`folds` 保持空数组。

**三条硬约束**，违反任何一条，标注保存后再打开会出错：

1. 图的宿主元素（`.fk-fig` 等）在源文件里是空的，内容只由 `XRAY.ready` 里的脚本画出。
2. 不自己调用 `renderMathInElement`，公式由 `XRAY JS` 统一渲染。
3. 不在 `XRAY.ready` 外面改 DOM。

原因：保存标注时，页面把载入那一刻的源码原样写回文件，只替换 `xray-notes` 这一块。在 `ready` 之前改过的东西会被一起写进去，下次打开就会重复。

## 2. 版式数值

reader-kit 已经实现了下面这些数值。列在这里是为了自检，不需要重写。

| 项 | 值 |
|---|---|
| 容器 | `max-width: 1560px`，左右内边距 48px |
| 栅格 | `224px minmax(0,1fr)`，`gap: 48px`。目录贴页面最左缘，正文从目录右边 48px 开始铺到右缘，不做居中窄栏 |
| 目录 | 由 h2、h3 自动生成；13px / 1.55，条目最多两行；当前节加 2px 强调色左竖条；不设 `overflow` 和 `max-height` |
| 行文宽度 | 段落、列表、卡片上限 88ch；有边注时自动收窄，给右侧留出 300px；图、表、代码、交互组件占满整列 |
| 顶栏 | 左上角四个纯文字键：☰ 目录、◐ 明暗、✎ 标注开关、⤓ 保存（有未写回的标注时右上角亮一个小点） |
| 进度条 | 2px，强调色，`opacity .38`，停止滚动 1.2s 后淡出 |
| 窄屏 | ≤1100px 目录收进浮层、边注改为插在段落下方；≤640px 内边距 20px，h1 25px，正文 16px |
| 字体 | 正文和标题 `Anthropic Serif`，界面 `Anthropic Sans`，代码和数字 `Anthropic Mono`；本机有字体文件就 base64 内联，没有就用回退栈。字体文件不进仓库 |
| 字号 | 正文 17px / 1.78；h1 31px / 700，下加 3px 双线；h2 22px，上间距 64px；h3 18px；数字 `tabular-nums` |

调色板（Claude Warm Paper）和角色色写在 CSS 变量里，暗色主题覆写同一批变量。正文里不写死十六进制色值。

页面自上而下：h1（自拟标题，说出核心洞见）→ `.info` 信息块（论文、作者、出处、链接、代码是否公开、一句话核心洞见）→ 一张 `.note` 说明颜色约定（一句话，只列这篇用到的角色）→ 正文。

## 3. 正文里的块

按需使用，不堆砌。正文是 HTML，加粗写 `<b>`，不要留下 Markdown 的 `**`，`XRAY.lint` 会报出来。

- **实验台段落** `<div class="bench">`：讲第一版实现在这一步失效时的具体症状、负责人会先跑的诊断、补丁和代价。用一档淡底色和正文区分，不加标题、不加标签词。每个机制小节最多一块，放在机制讲清楚之后。
- **步骤串** `<div class="steps">`：多步推导走三步以上时使用。每步前放 `<div class="st">step one</div>` 这样的等宽小标记，后面一行说这一步做什么，公式独占一行。
- **边注** `<span class="side">`：符号的另一种读法、一个数字的来源、一个反例。窄屏时自动变成段内小块。
- **Note / Warning**：`<div class="note">` 放容易忽略的提醒，`<div class="warn">` 放论文没说清的地方或陷阱。第一个 `<b>` 是两到四个字的标签。
- **符号胶囊** `<span class="pill r-in">x_t</span>`：正文提到核心符号时使用，文字颜色取它的角色色。
- **代码** `<details class="code"><summary>代码 · 文件名</summary><pre class="code" data-label="文件名">…</pre></details>`：默认折叠。注释用 `<span class="c">`，关键字和数字用 `<span class="n">`，不用彩虹式语法高亮。
- **表格** `<table class="t">`，数字列默认右对齐；以文字为主的表用 `<table class="t left">` 整表左对齐。表注 `<p class="tcap">`；需要强调的行加 `class="hl"`。
- **论文原图** `<figure class="pf"><img src="data:..."></figure>`，图下一两句话说该看哪里。

不用**如果你真读懂了，应该能回答**这类自查块。

## 4. 图的视觉语言

一句话：**颜色是第二套记号，图里只放名字和符号，解释全部写在正文。** 下面每条都是硬规则，HTML 和 MD 的自绘图都适用。

- **颜色表示角色**：输入 `--in` 蓝、输出与概率 `--out` 橙、带参数的变换 `--op` 绿、归一化与相加 `--norm` 黄、损失与失败 `--loss` 橙红、论文新部件或第二路输入 `--alt` 紫、参数 `--param` 粉（只作文字）、连线与注释 `--wire` 灰。同一角色在公式、正文、图、交互里永远同一色。一张图最多五种角色色加灰。
- **方框**：角色色 1.5 描边，角色填充，同色文字，圆角 4.6。框内只写运算名，1 到 3 个词，最多 3 行。同一行的框等高 60，宽度只用几档：LN 33、Linear 60、FFN 73、Attention 91、Embedding 85。
- **参数**：写在框正下方，12 号粉色斜体。**形状**：标在线的上方，灰色。**输入输出**：不加框，角色色文字加一支同色箭头。
- **连线**：灰 1.3，只走水平和竖直，直角拐弯。箭头是小实心三角，尖端正好碰到框边。分叉点是灰色小圆点。残差从分叉点抬起，横过去，落进黄色 ⊕。
- **重复块**：放进一个圆角容器，`N×` 写在容器外。最多一层容器。
- **字**：图里用 KaTeX 字体，框内 13、参数和注释 12、输入输出 15，任何字不小于 11。viewBox 宽不超过 1260，窄屏横向滚动，不缩字。
- **图里不放**：标题、Figure 编号、图例框、解释段落、阴影、光晕、渐变、任何 SVG filter、流动虚线。图号和一句话结论写在图下的图注里。
- **公式可以进图，只进一条**，符号按角色上色：`\role{out}{a}=\mathrm{softmax}(\role{param}{W}\role{in}{x})`。
- **高亮就是让其余退后**：被看的元素换成高亮填充、描边加粗到 2.8，相连的线从 30% 升到 100% 不透明，其余原地不动。要报一个数，从高亮元素拉一条同色直线到空白处写出来。
- **矩阵**：格子灰底灰线，被看的格子用角色色描边加高亮填充；行列标签在网格外。**张量**：角色色方格，三阶张量用斜投影，维度箭头在外侧。

**三个例外**，只允许出现在对应的组件里：

1. **文本热度**（`FK.heat`）：权重用词背后的柔和光晕表示，颜色取角色色，强度按行归一化。适合注意力、显著性、对齐分数这类落在词上的量。
2. **逐级放大**（`f.zoom`）：一个框拉出灰色楔形，展开成带灰色标题栏的面板，标题栏只写组件名，面板里可以再放大一层。适合有嵌套结构的模块。默认展开，点击原框折叠或展开。
3. **等轴线描**（`FK.iso`）：参照 Hairline 的做法，画成等轴测的线描立体，不透明板面，每块只有一条轮廓和一条折痕；只有描边会被点亮，图里不写任何字，名字写在图下的读数行。适合层叠、分层、堆栈一类的结构。它只在**层与层的叠放关系本身就是要讲的内容**时使用，一篇最多一处，不拿来当默认的配图。

**选组件**：

| 要讲的东西 | 用 |
|---|---|
| 数据流、架构、计算顺序 | `f.row` + `f.skip` + `f.stack`；有嵌套就加 `f.zoom` |
| 落在词或位置上的权重 | `FK.heat`（阶梯式看全貌，点选式看一行） |
| 层叠、分层系统、存储层级 | `FK.iso` |
| 一个运算把输入变成输出 | 双栏联动（左网络、右矩阵） |
| 一个参数的作用 | 滑块驱动一张会变的图，重点让读者看到在哪个取值附近开始失效 |

**数据图和 token 图**：kit 另有两个组件。`FK.plot(host, {x, y, w, h})` 画坐标图，`x`、`y` 可设 `log`、`ticks`、`fmt`、`hide`；`line / dot / text / rect / vline / hline` 每个元素带 id，滑块回调里用同一个 id 再调一次就原地重画，`line` 加 `tween:true` 时步进切换会平滑过渡。轴线用灰色，系列用角色色，图例不进图，曲线名直接写在曲线旁。`FK.tokens(host).set(lines)` 把切分结果画成深浅交替的 token 块，被切开的半个字符显示为橙红的十六进制字节。滑块驱动的图优先用 `FK.plot`，不要只改表格里的数字。

**形式不要只会一种**。上面三个组件是兜底，不是全部。同一个读者连着看的几篇，主图的形式要换；参照项目里还有很多可借的形式：Transformer Explainer 从总览点进细节、每一层显示真实数值；anatomy 把一个对象拆开，拆开的过程本身就是解释；Hairline 用单个物体的线描承载一个机制；3Blue1Brown 让一个量连续变化、读者看着它变形。先想这篇文档里最值得被看见的那个变化是什么，再选形式，不要先选组件再找内容去填。

弱模型最容易画坏、必须逐条防住的问题：

- 圆角彩框里塞一段小字；
- 字压线、字叠字；手写坐标导致字不居中；字缩到 9 或 10px；
- 箭头没碰到框，或穿进了框；斜线乱飞；
- 一个框一个颜色；一张图塞超过 12 个框（应该拆成两张，或者用 `f.zoom` 分层）；
- 容器套容器；
- 只在亮色或只在暗色下看得清；
- 中文框内标签过长（改用论文的英文名，或 2 到 6 个汉字）。

**怎么画**：只用 figure-kit 的 API 搭图，不手写 SVG 坐标。文件里有一张完整的编码器-解码器架构图、一个三级放大图、两种文本热度图和一个层叠图，照着改。

## 5. 交互：图本身就是界面

每个交互图首先是一张完整的静态图，不点任何东西直接截图也能放进书里。交互只做三件事之一：换一个被高亮的元素、改一个参数、往前或往后走一步。

控件只允许这几种，一张图最多一行，放在图下方、与图左对齐，没有外框、没有底色：

- **直接点图**（首选）：悬停预览，点击锁定，Esc 复位；
- **滑块**：1px 灰色细轨加一个一眼可见的空心圆形滑头（kit 已默认提供，不要覆盖成透明），左边是参数符号，右边是当前值。滑块必须驱动一张会变的图：拖动时图里的曲线、形状或高亮跟着动，不能只改一张表里的数字；
- **逐步**：`‹ 2 / 5 ›` 后面紧跟这一步的一句话，键盘左右键同样可用，默认不自动播放；
- **先猜一下**：同一行里的文字链接。

一律不要：图上方的工具条、FIG. 编号条、只有图标的小按钮排成一排、9 到 10px 的等宽状态读数、下拉框、复选框、带底色的按钮、胶囊按钮组、悬停弹出的黑底提示框、角落里写着 click a node 的提示。

**从总览走到细节**：Transformer Explainer 是这种做法的参照。先给整体的静态图，读者点某一部分才展开到下一层，展开后的数值和总览里的保持一致。每个交互组件对应正文里一个具体疑问：上方一句话说操作之后该看到的变化，下方一句话说明这个变化的含义。

**动画**：

- 一屏只动一个变量；
- 关键设计揭晓前留一个让读者先猜的停顿；
- 每步 300 到 600ms，缓动 `cubic-bezier(.4,0,.2,1)`；
- 只用 `requestAnimationFrame` 或 CSS transition，同一时刻只有一个 rAF 循环；
- `prefers-reduced-motion` 时直接跳到终态；
- 数字用 `tabular-nums`；
- 每个组件初始状态就有内容；
- 滑块两端不出现 NaN 或越界；
- 构造的数字标注**示意**，论文里的数字注明出自表几、图几。

公式着色写 `\role{角色}{符号}`。写在 HTML 里的公式，`<` `>` `&` 改写成 `\lt` `\gt` `\&`。

## 6. 标注层

reader-kit 自带标注层，读者不需要装任何东西。

- **开关**：✎ 打开后，选中文字会弹出小工具条，有**划线**、**笔记**、**反馈**三项；反馈再分**不懂**、**啰嗦**、**已懂**。关闭 ✎ 时，选中就是普通的选中。
- **笔记卡片**：显示在右侧边栏，用细线连回原文，窄屏时插在段落下面。
- **撤销**：右键划线或卡片，菜单里有撤销。
- **折叠**：每个 h2、h3 左侧有小三角，可以把整节收起，只留标题。
- **保存**：
  - 标注先自动存进浏览器本地。
  - ⤓ 把标注写回这个 HTML 文件本身，写在 `<script type="application/json" id="xray-notes">` 里。
  - Chrome 和 Edge 第一次选一次文件，之后自动写回；其他浏览器下载一份新文件替换原文件。
- **下一次运行时**：skill 会读这个块，评估读者的掌握情况（见 SKILL.md 的读者档案一节）。

作者不需要为标注层写任何代码，只要遵守第 1 节的三条约束。

## 7. 技术约束与自检

**约束**：

- 单文件，原生 JS 加 SVG/Canvas，不引框架、不需要构建。唯一外部依赖是 CDN 的 KaTeX，离线时公式退化成源码，其余功能照常。
- 论文原图 base64 内嵌；合计超过约 20MB 时改用 `file:///` 绝对路径。
- 只需要静态图的地方，用 matplotlib 出 PNG 再内嵌，脚本留在输出目录。

**交付前逐条过**：

1. 把所有内联 `<script>` 抽到临时文件跑 `node --check`（有 node 时），查完删掉。
2. 有 Chrome 或 Edge 时，跑 `chrome --headless=new --virtual-time-budget=8000 --dump-dom "file:///…/x.html?lint"`：
   - 读 `<pre id="xr-lint">`（XRAY.lint 检查标题问句、破折号、引号数量、空的图宿主、残留的 Markdown 记号、`xray-notes` 元数据）和 `<pre id="fk-lint">`（FK.lint 检查重叠、字太小、出界、字溢出框、字压线、用了 filter）。
   - 两者都清零才交付。
3. 用 `--screenshot` 加 `?theme=dark` 和 `?theme=light`，各截一张 1440 宽和一张 560 宽，自己看一遍。
4. 每张图对照第 4 节的**图里不放**和**最容易画坏**两张清单过一遍。
5. 目录贴最左缘，没有滚动条；亮暗两套下卡片、代码块、表格层次分明；刷新后主题保持，不闪白。
